# 班级公约

从侧栏的“班级公约”进入管理页面，也可在快速登记的“全部公约”中点击“查看与管理公约”。支持按类别筛选、搜索事项或说明；点击公约名称即可打开完整内容。

## 权限

| 操作 | 管理员 | 学生记录员 |
|---|---|---|
| 查看、搜索、筛选公约 | 支持 | 支持 |
| 导出有效公约 | 支持 | 支持 |
| 使用公约登记加减分 | 支持 | 支持 |
| 新增、修改、删除和恢复公约 | 支持 | 不支持 |
| 查看已删除公约 | 支持 | 不支持 |

演示班级可体验上述操作，刷新后重置；真实班级的公约保存在服务器。

## 新增与修改

每条公约包括事项名称、类别、单次分值和可选说明。分值为 −100 至 100 之间的非零整数，正数加分、负数扣分；说明可填写适用条件或老师确认的执行方式。最多保留 200 条有效公约。

保存后的公约可用于后续快速登记。修改公约不会改写已登记的事项、分值、次数、撤销记录或排行榜历史数据。

若同一公约已被其他页面修改，保存会提示版本冲突。点击“取消本次编辑并刷新”，放弃本次尚未保存的修改，重新查看最新公约后再编辑，避免覆盖他人的更新。删除遇到冲突时，可点击“返回列表并刷新”后重新核对目标。

## 删除与恢复

删除需要确认。已删除公约不再出现在登记选项或公约导出中，历史积分保留。管理员可在“已删除”列表查看并恢复；恢复后重新出现在有效公约列表。

首次建立公约列表时提供默认项目。主动删除全部公约后，列表保持为空，不会自动重新填入默认项目。

## 与待提交登记联动

已选公约被修改或删除时，快速登记会提示核对。点击“更新待提交事项”后，保留仍有效事项的次数，更新其公约内容，并移除已经删除的事项；重新确认小计与合计后再提交。名称和分值相同的不同公约仍作为独立事项保留。

手动登记事项只用于本次草稿，不会自动新增为班级公约。若登记请求的保存结果尚未确认，先点击“重试确认这批”，使用原批次确认结果，避免重复计分。

## 导出公约

“导出全部公约”生成独立 Excel 文件，包含当前全部有效公约，不受搜索或类别筛选影响。列为序号、类别、事项、类型、单次分值和说明，并显示班级名称、导出日期与条目数。

文件支持冻结表头、筛选和说明换行，分值保持可计算的数字。公约为空时导出只有表头的空表；不会导出学生姓名、个人积分或已删除的公约。
