# 管理员清空积分记录

管理员登录后，进入 **班级设置 → 数据管理 → 清空积分记录**。核对记录数量，输入“清空积分”和独立操作密码后确认。初始操作密码是 `00000`（五个零），与管理员登录密码不同。

清空会删除本班所有加分、扣分记录，包括已撤销记录，让全班积分归零。学生名单、班级公约、班级设置和登录账号保留。学生记录员没有这项权限；没有积分记录时按钮不可用。

系统先备份，再清空。备份失败时不会删除记录；确认过程中有人修改记录时，会中止清空，需刷新后重新核对。处理中请等页面返回结果。如网络中断导致结果不确定，请刷新查看最新记录后再操作。

## 备份与配置

- 备份目录由 `BACKUP_DIR` 指定；未指定时使用 `DATA_DIR` 同级的 `backups` 目录。
- 文件名为 `tongbanji-before-clear-时间-随机标识.sqlite`。备份包含完整数据库，目录权限为 700、文件权限为 600，不提供公开下载链接。
- 页面不支持撤销。需要恢复时由维护人员使用备份处理；恢复整个数据库会覆盖备份之后的新记录，需先停写并备份当前数据。
- 可通过服务器环境变量 `DATA_RESET_PASSWORD` 设置独立操作密码，修改后重启应用。不要将实际配置文件提交到仓库。Docker Compose 已传入此变量。
- 保留登记批次去重信息，防止清空前提交过的请求重试后恢复旧积分。清空后可以正常登记新记录。

无需数据库迁移。服务端验证登录、管理员权限、请求来源、确认文字、操作密码和记录版本；备份通过完整性检查且确认版本一致后，在事务中删除本班积分记录。
