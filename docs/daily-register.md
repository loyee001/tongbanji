# 每日登记空表

在登记台顶部点击“导出登记空表”，选择日期或勾选“日期留空，打印后手填”，再下载 Excel。

空表包含班级内的全部学生，按学号数字顺序排列。表格只有四列：学号、姓名、加分事项及次数、扣分事项及次数。后两列留空，表头提供“举手 × 3 次”“课间违纪 × 3 次”的填写示例；没有合计栏，也不会填入已有积分或历史记录。

42 名学生可打印在一张 A4 纸上。每页最多 42 人，各页重复班级、日期、记录员填写栏和表头，并显示页码。Excel 的每个工作表对应一页，已设为 A4 竖向、黑白打印；打印时选择“打印整个工作簿”，即可打印全班名单。表格保留加减分手写空白栏，使用紧凑行距。

回到网站后，按纸上的事项选择公约和次数进行补录。空表导出本身不会修改班级或积分。
