# 快速登记

1. 选择一位或多位同学。
2. 选择一项或多项加减分事项。
3. 每项设置 1–100 的整数次数，系统显示单次分值 × 次数的小计和每人合计。
4. 提交前可修改同学、事项名称、类别、单次分值、次数及日期，也可移除事项。
5. 点击确认登记后才计入积分。

多人登记时，每项次数应用于全部已选同学。一次最多选择 50 项事项。

保存失败会保留填写内容。若无法确认服务器是否保存成功，草稿会暂时锁定，点击“重试确认这批”确认原批次；重试不会重复计分。明确拒绝后可继续编辑。

旧记录经 `drizzle/0002_entry_quantities.sql` 迁移为 1 次，已有积分与撤销审计保持不变。新记录和 Excel 明细包含单次分值、次数与合计分值；排行榜和积分汇总按合计分值计算。

批次写入为事务操作，任一事项失败会回滚整批；批次编号与内容摘要用于幂等校验。已撤销记录重试不会恢复。
